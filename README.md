# ORIGEN

> **Enterprise Portfolio Project**\
> Plataforma Full Stack desarrollada para demostrar arquitectura, buenas
> prácticas y desarrollo empresarial con **Java 21, Spring Boot 3,
> Angular 20 y SQL Server**.

## Objetivo

ORIGEN es un proyecto de portafolio cuyo propósito es demostrar
conocimientos en:

-   Arquitectura de software.
-   Desarrollo Backend con Spring Boot.
-   Desarrollo Frontend con Angular.
-   Diseño de APIs REST.
-   Seguridad mediante JWT.
-   Persistencia con JPA.
-   Versionamiento profesional utilizando Git Flow y Conventional
    Commits.
-   Contenerización con Docker.

El proyecto evolucionará mediante commits pequeños y bien documentados.
